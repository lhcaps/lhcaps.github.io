**Approach:** Build the final English Systems Atlas contract: one typed public graph, warm-paper semantic DOM, one optional finite Canvas, deterministic evidence/CV/history, and exact-SHA Pages attestation.

## Boundaries & Constraints

**Always:** Preserve exact identity/destinations/System titles/60–40 positioning/**Work with me**; keep DOM meaning complete; use at most one eligibility-gated lazy Canvas; follow local-font, responsive, motion, accessibility, Claim-limitation, TDD, exact-pin, privacy, and fresh-verification contracts.

**Ask First:** New personal or outcome facts, canonical-contract changes, unapproved credentials/external effects, destructive changes beyond the exact trailer rule, or remote drift that changes the candidate.

**Never:** Publish private/internal evidence or sensitive values; invent runtime/production facts; add portrait, remote fonts, dark glass/neon/particles/orbit, multiple Canvases, ambient loops, scene-only meaning, advisory waivers, reset/clean/stash/worktree/broad staging, or an unverified push.
